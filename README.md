# SCAU 编译原理 综合性实验

## 实验题目
* 选择部分C语言的语法成分，设计其词法语法语义分析程序。（参考教材附录C.5）

## 实验内容
* 设计并实现一个一遍扫描的词法语法语义分析程序，将部分C语言的语法成分
（包含赋值语句、if语句、while循环语句）翻译成三地址代码，要求有一定的出错提示和错误恢复功能。

## 程序功能
* 词法分析：将输入的C语言代码进行词法分析，并输出词法分析结果。 
* 语法分析：将词法分析的结果进行语法分析，并输出语法分析结果。 
* 语义分析：将语法分析的结果进行语义分析，并输出语义分析结果。

## 实现效果
* 分析赋值语句+if语句+while循环语句，生成四元式并有错误提示。

## 运行说明
* 将需要语法语义分析的C语言程序写入data.txt 
* 运行程序Main
* 控制台输出语法语义分析结果
